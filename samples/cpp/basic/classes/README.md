## Build using vscode tasks

1. Enter [main.cpp](./main.cpp)
1. Open the Command Palette (Ctrl + Shift + P)
1. Select **Tasks: Run Task**
1. Select **cmake: configure**
1. Build by using **cmake: build**
1. Run by using **cmake: run**

When you have run **cmake: configure** and the build folder hasn't been removed/modified elsewhere, you can just run the **cmake: build** task to re-compile. The **cmake: run** task also allows for recompilation.
